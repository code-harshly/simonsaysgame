# Simon Says Game

This is my first browser game project. It is a simple Simon Says memory game built with HTML, CSS, and JavaScript.

## How to play

- Press any key to start the game.
- Watch the flashing tile sequence.
- Repeat the pattern in the same order.
- Each successful round increases your level and score.
- If you make a mistake, the game ends and your final score is shown.

## Features

- Randomized sequence generation
- Increasing difficulty as the level goes up
- Score tracking
- Visual flash feedback for correct and incorrect actions

## Run it locally

1. Open `index.html` in a browser, or
2. Serve the folder using a local web server such as:
   `python3 -m http.server`
3. Then visit `http://localhost:8000` in your browser.

## Project files

- `index.html` — page structure
- `simon.css` — styling for the game board
- `simon.js` — game logic and score handling
